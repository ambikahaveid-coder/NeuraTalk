### Key Architectural Decisions

```
1. Proprietary Audio Pipeline
   Why: Full control over audio processing
   Benefit: Emotion detection, phrase-level translation
   Risk: No fallback if breaks

2. Phrase-Level Translation (not sentence-level)
   Why: 300ms latency requirement
   Benefit: Real-time feel, low latency
   Risk: Context might be lost

3. Voice Training System
   Why: Custom voice cloning for users
   Benefit: Personalization, branding
   Risk: Ethical concerns (deepfakes)

4. Multi-Role Architecture
   Why: Different user types (consumer, agent, admin)
   Benefit: Flexibility, scalability
   Risk: Complexity in testing

5. Real-Time Translation + Call
   Why: Unique selling proposition
   Benefit: Only platform doing this in India
   Risk: Complex, many things can break
```
