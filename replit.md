# NeuraTalk - Voice AI Chat Application

## Overview
NeuraTalk is a voice-first AI chat application designed for natural, emotionally intelligent, and culturally aware conversations, offering real-time speech-to-text and text-to-speech for B2B and B2C markets. Its core vision is to build emotional trust and ensure users feel respected and understood through a proprietary, self-hosted communication infrastructure supporting multiple languages and mixed-language contexts. The project aims to deliver premium, calm, and intelligent AI interactions with robust organization management.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Architectural Principles
NeuraTalk adheres to a "Dependency Zero Policy," prohibiting external SaaS, paid APIs, cloud vendor-specific services, or black-box SDKs for core functions, relying solely on open-source, auditable, self-hosted services. The system prioritizes graceful degradation, user trust, flexible evolution, OS security sandbox respect, and strict auditing of call state and user consent. Core intellectual property (signaling, audio processing, emotion handling) is built for long-term platform ownership and explainability.

### Frontend
- **Framework**: React 18 with TypeScript
- **State Management**: TanStack React Query
- **Styling**: Tailwind CSS with shadcn/ui

### Backend
- **Runtime**: Node.js with Express
- **Language**: TypeScript with ESM modules
- **API Pattern**: RESTful endpoints

### Data Storage
- **Database**: PostgreSQL
- **ORM**: Drizzle ORM
- **Schema**: Covers users, organizations, conversations, voice profiles, billing, subscriptions, invoices, usage, GST, devices, call telemetry, and enterprise API keys.

### Authentication
OTP-based (email/SMS) passwordless login with bearer token authentication (24-hour rolling expiry) and a five-tier role system. Session storage is backed by PostgreSQL.

### Enterprise API & SDK
Full API/SDK system for enterprise customers with activation key management:
- **API Keys**: Generated by super admin with `ntk_ent_` prefix, SHA-256 hashed for storage
- **Activation Flow**: Keys start as "pending" → super admin activates → key becomes "active"
- **Key States**: pending, active, suspended, revoked
- **SDK Endpoints**: `/api/sdk/translate`, `/api/sdk/tts`, `/api/sdk/stt`, `/api/sdk/languages`, `/api/sdk/usage`, `/api/sdk/voice-chat`
- **Authentication**: X-API-Key header
- **Rate Limiting**: Per-minute rate limit (default 60/min), daily quota (default 1000)
- **Usage Tracking**: Per-key usage counts, daily reset, last-used timestamps
- **Admin Management**: Super admin can create, activate, suspend, revoke keys from dashboard
- **SDK Docs Page**: `/sdk-docs` with code examples in JS, Python, cURL
- **Files**: `server/enterprise-api-routes.ts`, `client/src/pages/website/SDKDocsPage.tsx`
- **DB Table**: `enterprise_api_keys`

### B2B Multi-Tenant Platform
Features self-service onboarding with approval workflows, a ledger-based credit system, and granular Role-Based Access Control.

### Production Billing System
Supports B2B (prepaid/postpaid) and B2C (time-based subscriptions) models with dynamic plan management, automatic GST compliance for India, and invoice generation.

### Self-Hosted Communication Infrastructure
A proprietary infrastructure handles voice communication:
- **Signaling Layer**: Custom WebSocket server for WebRTC call initiation.
- **Voice AI Chat Layer**: Dedicated WebSocket server for AI voice chat.
- **Media Relay Layer**: Self-hosted RTP/UDP media server.
- **Native Telephony Bridge**: Integrations for Android (TelecomManager + InCallService) and iOS (CallKit + VoIP push) for SIM audio routing.
- **Multi-Platform Call Support**: Deep link generation for platforms like Microsoft Teams, Zoom, WhatsApp, Google Meet.
- **Real-time Voice Features**: Browser MediaRecorder, server-side ffmpeg, custom AudioWorklet for PCM16 audio streaming.
- **Call Bridging System**: SIM-to-SIM call bridging with bidirectional live voice translation, emotion preservation, and call state management.
- **WebRTC Real-Time Translation**: Browser-to-browser calls with real-time audio capture, STT, translation, and emotion detection.
- **Video Translation Calls**: Real-time video calls with audio translation overlay.
- **Lip-Sync Architecture**: Infrastructure for Wav2Lip/SadTalker integration via self-hosted GPU processing.

### AI Capabilities
- **Audio**: Speech-to-text, text-to-speech, voice chat.
- **Chat**: Text-based conversation management with streaming.
- **Human-like AI Behavior**: Natural conversation, emotional intelligence (empathetic responses, energy matching), language auto-detection, and conversation flow with micro-pauses via an Emotion Engine.
- **Voice Training System**: Allows users to record voice samples for personalized voice models.
- **Voice Cloning & Preservation**: Real-time voice cloning using self-hosted RVC/XTTS to preserve the user's natural voice during translation, maintaining original speaking style, pitch, and emotion.

### EzDubs-Inspired Features
Multilingual communication for real-time translation:
- **Voice Memos**: Record voice messages with automatic transcription, translation, emotion detection, and encrypted storage.
- **Multi-language Group Chats**: Group conversations with real-time translation of text and voice messages.
- **Translation Pipeline**: STT → Language detection → Translation → TTS with voice profiles.
- **Security**: AES-256-GCM encryption, authenticated access, and path tampering protection.

### Production Readiness
Emphasizes real-world testing, self-hosted observability, mode separation, feature flags, and rigorous Human QA. Adheres to data minimization and strict engineering discipline.

### Mobile App (React Native & Flutter)
Both React Native and Flutter apps provide native SIM-to-SIM call bridging with translation, integrating with Android TelecomManager/InCallService and iOS CallKit/VoIP Push. The Flutter app includes comprehensive video/voice call implementation and Firebase Auth.

### Enterprise Compliance
Includes legal pages (Privacy Policy, Terms of Service, DPA), cookie consent, GDPR/DPDP rights implementation, security headers, IP whitelisting, session management, custom roles, bulk import, SLA management, and audit logging.

### WebRTC Infrastructure
Utilizes Twilio Network Traversal Service for STUN/TURN servers for reliable WebRTC connections, with public STUN servers as a fallback.

### Self-Hosted AI for Ultra-Low Latency (<0.3s)
Following the "Dependency Zero Policy," core AI models are self-hosted for ultra-low latency operations:
- **Local Whisper**: Self-hosted STT.
- **Local Translation**: LibreTranslate or NLLB.
- **Ultra-Low Latency Mode (<100ms)**: Streaming pipeline for near-instantaneous translation.

### Progressive Web App (PWA)
The web application is PWA-enabled, offering offline caching, background sync, install prompts, and a native app-like feel on mobile devices.
